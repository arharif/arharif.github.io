# Academic interface

The scoped palette uses navy backgrounds, slate panels, teal actions and muted violet AI accents. Light mode uses white panels and dark text. Semantic status messages include textual labels and do not rely on colour. Typography uses locally available system sans-serif fonts without a new network font dependency.

The layout has a compact gateway header, a persistent desktop learning navigation, breadcrumbs and a single reading workspace. Mobile navigation scrolls within its own region. Text fields, selects, buttons and details remain native keyboard-operable elements. Labels are visible. Focus rings identify controls. Route transitions move focus to main content. The programme does not add animated backgrounds. Reduced-motion preferences disable scoped transitions.

Cards navigate to a specific capability. Tables hold the full metric values and assessment records. The AI chart is decorative because its complete numeric alternative is in the threshold table. Concept nodes are buttons with selected state and adjacent explanations, plus a full reading alternative. Existing role graphs remain accessible through their established route, with the academic role list providing a direct learning alternative.

Responsive checks cover 320px, 768px and desktop viewports. Dedicated tables can scroll within labelled workspaces. Manual screenshot review found overlapping mobile navigation labels that an overall viewport-width check missed. Links now resist flex shrinking, and a browser assertion checks adjacent item bounds. Automated accessibility checks cover both dark and light modes. These checks complement human assistive-technology review and do not establish full WCAG conformance.
