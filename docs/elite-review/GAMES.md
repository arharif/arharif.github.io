# Arcade additions

Bubble Blitz adapts the paddle movement, wall reflection and target removal from lesson 10 of the Gamedev Canvas Workshop by Andrzej Mazur and Mozilla Contributors, revision `5199692d8acb9770dc5c16b5b18afbadd95fa497`. The authors dedicate the code samples to the public domain under CC0 1.0. Their tutorial prose has a separate CC BY-SA 2.5 licence. X1 supplies the instructions, game art, circular targets, three-life scoring, controls and React lifecycle. No upstream images, prose, audio, packages or services are included. [Source](https://github.com/end3r/Gamedev-Canvas-workshop/blob/5199692d8acb9770dc5c16b5b18afbadd95fa497/lesson10.html) · [Licence](https://github.com/end3r/Gamedev-Canvas-workshop/blob/5199692d8acb9770dc5c16b5b18afbadd95fa497/LICENSE)

Neon Stack is an original X1 implementation covered by the repository's Apache-2.0 licence. Each placed block retains its overlap with the previous one. Twelve placements win. Both games draw their own graphics and use the existing local Arcade progress system.

The MIT-licensed 2048 implementation by Gabriele Cirulli was also considered. The existing Arcade already has a playable 2048 game, so it keeps its original implementation. [Upstream licence](https://github.com/gabrielecirulli/2048/blob/master/LICENSE.txt)
